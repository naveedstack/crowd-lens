Protocol Architecture

Validator Reputation & Security FAQ

Everything you need to know about devnet consensus, slashing prevention, and escrow distribution.

help_outline What is the 80% reward pool?

When creators initiate an asset test on CrowdLens, they escrow a set fee (standard: $1.00 per vote quota). The CrowdLens smart contract program automatically earmarks 80% ($0.80 denominated in SOL) to the validators who participate in the consensus round. The remaining 20% sustains cluster RPC relays and indexers.

sync_alt How does consensus alignment work?

CrowdLens uses a blind commit-reveal consensus mechanic. Validators evaluate assets without seeing others' choices. When the quorum threshold (e.g. 25 validators) is achieved, ballots reveal simultaneously. Validators who align with the plurality outcome receive immediate escrow disbursement plus reputation multipliers.

lock_open Do I need to stake SOL or buy tokens?

No. CrowdLens operates on Solana Devnet and requires zero token purchases, zero staking minimums, and zero hardware requirements. Anyone with a Phantom or Solflare wallet set to Devnet can connect, request test SOL from our faucet, and start voting immediately.

bolt When do earnings arrive in my Phantom wallet?

Directly and instantaneously upon round finalization. Because settlement is triggered by an atomic contract instruction, there is no withdrawal queue, no manual admin approval, and no minimum balance requirement. Funds exist in your wallet address within seconds of quorum completion.
